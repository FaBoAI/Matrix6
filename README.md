# Matrix6

ESP32-S3-WROOM-1-N8R8 development board in KiCad 10.

This first snapshot preserves the manually routed DevBoard v0.4, including the USB connector body keepout, continuous L2 ground plane and `Designed By GPT-6 Astra` silkscreen. The original header spacing is 30.48 mm; this snapshot does **not** mate with Matrix5 shields. The following revision migrates to the measured Matrix5 interface.

Open `hardware/Matrix6/Matrix6.kicad_pro`.
