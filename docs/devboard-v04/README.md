# DevBoard v0.4の履歴資料

このフォルダーはMatrix5端子への移行前の設計・検証記録です。現行設計は [Matrix6 v0.5](../../README.md)、CADは [hardware/Matrix6](../../hardware/Matrix6) にあります。

v0.4は35.56 × 61 mm、ヘッダー列間30.48 mmで、Matrix5シールドの位置・端子割り当てに対応していません。ヘッダーの外部5 V入力を説明した記述も旧設計の条件です。**現行のH1.1/H2.1は出力専用**で、給電条件は [v0.5互換性資料](../matrix5-compatibility.md) を参照してください。

[電気設計レビュー](electrical-review.md)は、引き継いだUSB形状・層構成・降圧回路の設計経緯を残すものです。このフォルダーの画像、DRC/ERC、SHA-256、元プロジェクト名や元のパスはv0.4当時の記録であり、現在のCADに対する検証ではありません。現行の結果は [../validation](../validation) にあります。

移行前のCADは初期インポートのコミット `ee580b181c5c248c455f0519c6c52200018bf0b3` に保存されています。
