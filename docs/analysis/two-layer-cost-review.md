# Matrix Six：2層化と製造コストの比較

> **履歴資料：v0.7の4層設計を対象にした事前調査です。** この後、ユーザーの2層化依頼により[v0.8の再設計](../matrix-six-v08.md)を完了しました。以下の配線数・穴径・金額はv0.7の記録であり、現行2層版の仕様・見積もりではありません。

2026-09-08、v0.7の保存済みCADとJLCPCBの見積画面を確認しました。**2層への再設計は技術的な選択肢ですが、現在の配線をそのまま2層へ減らすことはできません。コスト目的なら、まず4層の製造条件を実データに合わせる方法を推奨します。**

この調査ではCAD、発注済みの未払い注文、製造用Gerber/BOM/CPLを変更していません。比較用の見積画面を作成した段階で、別注文は作成していません。

## 2層化に必要な変更

- 内層In2.Cuには38ネット・110線分、合計580.659 mmの配線があります。表裏への再配線と、GNDを確保するための部品配置の再検討が必要です。オートルーターは使用しません。
- 現在のUSB直下のGNDはIn1.Cuで13,182検査点すべてを覆っています。B.Cuの既存GNDでは6,463点に欠損があり、そのままUSBの参照面にはできません。USBを表面・ビアなしとする条件を維持し、裏面に連続したGND経路を確保する再設計が必要です。
- 4層での約91.1 Ωという断面計算結果は、2層へ流用できません。基板厚、材料、配線幅・間隔・周囲GNDを再計算する必要があります。
- ESP32-S3の設計ガイドは2層構成も扱っています。一方、USBについては90 Ω±10%、等長の並行配線、連続した参照面を求めています。[Espressif設計ガイド](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/pcb-layout-design.html)
- JLCPCBの標準FR-4の管理インピーダンス対応は4層以上です。2層にする場合は、設計計算と試作・測定による検証へ条件を変更する必要があります。2層版はまだ製造承認できる状態ではありません。[JLCPCB製造能力](https://jlcpcb.com/capabilities/pcb-capabilities/)

Matrix5の端子位置、R2外形、USB脇のRESET/BOOT、下側のPOWER/PIN 48 LED、裏面microSDの抜き差し空間、LiPo充電・電源切替は維持する前提です。両面実装のままなので、2層化だけでは実装工程の基本費用はなくなりません。

## 4層のままで削減できる費用

実データの通常ビアは150個すべて穴径0.3 mm／銅箔径0.6 mmです。最小穴はU1のサーマルPTH 12個の0.2 mmで、銅箔径は0.6 mmあります。前回の見積もりでは `0.2mm/(0.3/0.35mm)` という微細条件を選択していましたが、実形状より厳しい条件です。

JLCPCBの見積画面の説明では、多層基板で銅箔径が0.45 mm以上の場合、0.2 mm穴にも微細ビア追加料金はかかりません。標準料金区分で比較したところ、微細ビア料金とそれに伴う4線式Kelvin試験料金がなくなりました。通常のフライングプローブ全数導通試験は維持しています。実際の穴径は0.2 mmのままで、ドリルデータを0.3 mmへ変更する意味ではありません。CAM確認時にこの穴・銅箔寸法と料金区分を明示する必要があります。[見積画面の製造条件](https://cart.jlcpcb.com/quote)、[穴径・銅箔径の規定](https://jlcpcb.com/capabilities/pcb-capabilities/)

比較は基板5枚、両面実装2枚、JLC追加レール込み70.64×71 mm、1.6 mm、紫、白シルク、ENIG 1u、FR4 TG155、外層1 oz／内層0.5 oz、JLC04161H-7628、インピーダンス管理±10%、エポキシ充填・銅キャップ、Horizontal Electroless Copper Plating、製造ファイル確認ありの条件です。

**基板費の削減は$33.79（約28%）**。実装費$162.42・OCS送料$8.79・割引$6.00が同じ場合、合計は$285.68から**約$251.89（約12%減）**になります。$86.68は比較画面の表示値で、$251.89は既存実装費・送料・割引を用いた計算値です。部品の再見積もり・CAMの料金区分確認はまだ行っていません。決済手数料、基板分割等の審査後費用、輸入時費用は含みません。

さらにビア充填を不要にするパッド・ペースト・放熱構造の変更も検討できますが、製造方法だけを切り替えるのは不適切です。色変更は別の外観選択になります。これらを今回の$33.79削減へ混ぜていません。
