基板5枚、実装2枚を見積もります。FR-4・4層・1.6 mm・紫・ENIG・外層1 oz／内層0.5 oz、JLC04161H-7628相当、USB差動90 Ωを指定。U1/U2のサーマルビアを平坦に充填・銅キャップし、コネクタの部品穴は開口を保持します。

Top 37部品、Bottom 11部品。J3とH1/H2はスルーホール接続を含みます。ヘッダーとSD/JSTの配置原点は本体中心に補正しています。JLCPCBの選択モデルに合わせ、H1/H2はKiCad角度に+90°、J2は+180°を適用しました。再アップロード後、ヘッダーが縦、SDの挿入口がアンテナ側であることを確認しました。

2026-09-07にライブ画面で全26グループを選択済み。BOMのLCSC番号に空欄はありません。充電器は4.2 V版、SDはDM3AT-SF-PEJM5、LiPoコネクタはPH2・1番BAT+／2番GND。USB4105-GF-A-120も元の型番を選択しました。在庫は発注まで変動します。

JLCPCBプレビューではU1/J1/J3等にモデル原点による可能性のある位置ずれが残り、最終実装位置・全極性の照合は未完了です。基準図、SDアクセス図、KiCad裏面3D図を実装備考へ添付し、実パッドに合わせたJLCPCBエンジニアの修正と確認図を要求しています。アンテナ張り出しはCAD上6.25 mmです。製造ファイル・実装位置の確認を有効にし、自動承認を停止しています。確認図の全パッド・極性・レール干渉を確認してから製造承認してください。
