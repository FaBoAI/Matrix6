## 見積もり条件

2層FR4、公称1.6 mm、両面1 oz、40.64 × 61 mm、四隅R2 mm。従来の外観は紫・白シルク・ENIG 1uです。基板5枚／両面実装2枚を比較の基準とし、JLC追加レールは部品の張り出し・両面実装条件に合わせて確認します。

銅箔ファイルはF_Cu.gtlとB_Cu.gblの2枚のみ。内層データはありません。最小完成穴径0.30 mm、通常ビア径0.60 mm、U1の12放熱穴は径0.30／パッド0.80 mm。放熱・パッド内ビアのエポキシ充填と銅キャップは必要です。U1の放熱穴は部品挿入穴として開口しないようCAMへ指定し、コネクタ穴・USB長穴・NPTHは開口します。

USB差動は表面のみ・ビア0、均一部分の幅0.380／線間0.180／両脇GNDまで0.200 mm。断面計算は約90.3Ωですが、標準2層での管理インピーダンス保証は前提にしていません。4層用7628スタックを指定しないでください。GND帯を保ち、形状変更は製造前に照合します。
